# Associative sweep (#88)

The approved parametric-9 payload stores one `LoftSection` and `path: { nodeId, edges: EdgeRef[] }`, with optional solid/round-corner settings. The default is a solid with right-corner transitions. Initial sections are single hole-free sketch profiles. References fail explicitly if missing or ambiguous; there is no stored-shape fallback.

Path refs are source-local. They resolve on the host feature input for self references, on the source's pre-consumption timeline when it later consumes the host, or on an ordinary source's current shape. A transient rollback source is refused. Matching retains whole split spans and per-reference anchors, then checks a connected ordered chain without repeated edges or branching. Geometry is transformed through source world placement into host coordinates before constructing the wire. The shared path resolver is also intended for associative projection (#89).

Tracked body and sketch paths use their actual source topology or entity identities. A newly picked untracked path receives one authored `path-ref:` UUID in the existing `EdgeRef.edgeId` field. An unambiguous geometric reanchor retains this token. The resolver never treats it as a native source ID, and reports its provenance as `authored` with `stable: false`. It preserves association with the pick, but cannot guarantee following arbitrary upstream reparameterization; missing or ambiguous geometry requires a new pick. The UUID interpretation was explicitly approved for the new path carrier and adds no stored field.

Native evaluation reuses `BRepOffsetAPI_MakePipeShell` and explicitly binds the section to the first path vertex. [OCCT 8.0.1 exposes a history-building flag](https://raw.githubusercontent.com/Open-Cascade-SAS/OCCT/V8_0_1/src/ModelingAlgorithms/TKOffset/BRepOffsetAPI/BRepOffsetAPI_MakePipeShell.hxx); it must be enabled before constructing the tracked result. Runtime history combines section and spine edge/vertex origins, plus first/last section roles. Output identities use source provenance and cap/seam/junction roles; they must not use output enumeration positions. Native validity and self-intersection checks gate acceptance.

This implementation is in progress. The original scan-specific failure has not been reproduced. Version registration, atomic merge fields, the new immutable fixture, editable creation/re-pick previews and MCP coverage will be committed with the feature after native history proof succeeds. Existing saved envelopes and fixtures remain unchanged.
