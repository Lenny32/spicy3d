# Groove and rib along a curve on a face (#90)

The approved parametric format 11 adds `faceSweep` with one `LoftSection`, ordered whole-edge `path: { nodeId, edges: EdgeRef[] }`, `support: { nodeId, face: ProfileRef }`, `operation: "join" | "cut"`, and optional `roundCorner`. The pure migration from 10 to 11 changes no existing payload. Section, path and support picks each merge atomically. The new immutable fixture rebuilds a cylindrical-wall rib and roundtrips through device export and cloud manifests.

The native operation copies all inputs before validation. OCCT's support-surface Darboux law controls the frame. Missing p-curves are attached only to owned edges; finite curve-on-surface error and tolerance growth are checked. Common/Cut verifies the entire path against the trimmed face. Crossing an inner trim, a nearby off-surface path, or a section not authored at the start perpendicular to the tangent is rejected. Initial scope is one hole-free profile, at most 256 path edges and 256 validation faces.

Runtime requires proven reusable path and support ancestry. `path-ref:` and `untracked:` tokens cannot establish native topology history. Native copy ModifiedShape maps preserve entering-body IDs. PipeShell history preserves actual section/path origins; support is composed explicitly as the causal frame origin. Boolean tracking uses native origins and exact IsSame identity. New intersection edges derive IDs from actual adjacent derived faces. Fingerprints and output enumeration cannot fabricate ancestry.

The result must attach to or intersect the entering body, change finite positive material volume, contain one connected valid solid, and pass self-intersection validation. Source edits refresh projected paths whose target host consumes them later: only notifications from that actual consuming host are suppressed. The host refreshes the producer against its entering timeline before evaluating the face sweep. Variable edits on consumed producers remain active.

Foundation proofs cover native cylindrical join/cut, unchanged input BREP, trim/off-surface/placement rejection, copy ancestry, upstream profile/path/support edits, retained IDs and downstream fillet, host placement cache invalidation, projected source edits without cache loops, ambiguous history/nonfinite overlap rejection, old fixtures, migration, atomic references and cloud/device roundtrip. Editor and MCP completion remains a separate checkpoint. The historical scan crash has not been independently reproduced.
