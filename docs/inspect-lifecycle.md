# Inspect analysis lifecycle and display ownership

An `AnalysisNode` stores the analysis kind, stable source references, editable settings, visibility, and name in the document's `AnalysisGroup`. It does not serialize result meshes, shaders, clipping planes, or native query objects. The analysis group is separate from the solid-producing feature history. Add, edit, hide, rename, and delete operate through the document transaction/history path.

`AnalysisManager` resolves source node IDs to cloned shapes or copied mesh data at evaluation time. A subshape reference uses a parametric stable ID when available. A plain subshape index is paired with a source topology signature and fails closed after a rebuild. Missing or ambiguous references set the analysis to invalid with a visible error. Nested node/group transforms are composed into a world transform before geometric evaluation. The manager owns the resolved clones and releases them after the evaluator finishes.

Each evaluation has a revision and `AbortSignal`. A source edit, settings edit, visibility change, deletion, or document close cancels its active run and removes its display. A completed older run cannot replace a newer one. Advanced face evaluators yield between small batches of rendered triangles; native OCCT calls themselves are synchronous and cannot be interrupted mid-call. A hidden analysis is idle and recomputes when shown. Expected query failure returns `Result.err`; a gray/unknown region indicates sampling or geometry that could not be classified and must never count as a pass.

The manager owns temporary overlay mesh IDs and result disposers. A result's `display()` returns a release function. The Three.js context grants token-based leases for the shared clip plane and per-node analysis appearance. For each affected node, the newest appearance lease wins; releasing it reveals the previous lease, and releasing the last lease restores the current source material. The newest clip lease wins; releasing it restores the previous clip or the renderer's preexisting clipping planes. A stale release function cannot clear a replacement lease with the same owner ID. The manager displays only the newest section's cap and restores the earlier cap when the newer section is hidden or deleted. Face-color maps and material appearance claim overlapping source nodes in newest-first order; a multi-source map is suppressed as a whole when any claimed source conflicts. Older appearance leases may remain installed beneath an opaque newer face-color overlay and reappear when that overlay is removed. Line combs, witnesses, and point markers remain independent. Newly opened views receive the active clip. Model picks, rectangle selection, camera pivot, and analysis-marker snapping reject clipped geometry. Section caps are separate temporary meshes from a positive half-space Boolean, preserving cavity holes; their display vertices shift 0.0001 mm into the retained side to avoid clipping precision artifacts, while kernel geometry remains exact. Source materials and source geometry are never edited by analysis display.

All dimensions use millimetres, square millimetres, cubic millimetres, degrees, inverse millimetres for principal curvature, and inverse square millimetres for Gaussian curvature. Curvature uses the face's outward normal: positive is convex and negative is concave. Draft is `asin(outwardNormal · pullDirection)` in degrees. A zero-draft band is centered on zero. Numeric settings reject nonfinite values and invalid ranges. Native queries guard null geometry, differentiability, finite domains, and valid solid topology before calling OCCT; Release WASM catches OCCT raises (`-fwasm-exceptions`, `cpp/src/guard.hpp`) as error results; the guards stay for clearer messages and as the safety net for a module built without that handling (the committed binary is built from the current sources: Emscripten 5.0.7, OCCT V8_0_1, 2026-09-30). A native unsupported state is an error or an explicit unknown sample, never a numerical zero.

Surface color maps evaluate exact derivatives at the UV centroids of the **rendered trimmed triangles**, after mapping normalized render UVs back to exact face UV bounds. This is a sampled visual diagnostic, so a region smaller than the tessellation can be missed. Curvature at singular, nonsmooth, or unsupported points is unknown. Isocurves use an exact kernel face/curve common to trim each line and avoid drawing through holes; displayed lines still follow tessellation quality. Directional access uses forward ray hits from sampled points and describes point access only, not finite-tool clearance. Local draft and radius checks do not establish global manufacturing feasibility. Sketch curvature display is outside this first body-edge inspector.

Draft and accessibility may use a saved direction source reference. `directionSourceIndex` identifies the exact source entry, allowing an edge or planar face on the same node as target geometry; `directionSourceId` checks that the source still matches, and `directionReverse` flips it. A planar normal uses the inverse-transpose world transform so nonuniform scaling cannot rotate it incorrectly. `targetSourceIndexes` and `obstructionSourceIndexes` separate sampled targets from access blockers. An invalid or lost reference invalidates the analysis instead of falling back to a stale raw vector. Similarity membership is an explicit node-ID list in each open document. Searches recompute descriptors from bounded candidates, and opening or closing a document refreshes affected searches.

Chrome and zebra appearance use a procedural studio reflection shader authored in this repository under the project's AGPL-3.0 license; no third-party environment image or remote asset is loaded. Studio and softbox controls select different band patterns. Reflection and zebra direction are evaluated in camera/view coordinates, so rotating the camera deliberately moves the pattern across a surface; rotation, density, contrast, and finish settings alter it without changing saved materials. Shader and overlay quality remains limited by the source tessellation.
